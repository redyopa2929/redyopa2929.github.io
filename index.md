# Tools Gratis Indonesia: Kalkulator & Konverter Open Source

Ini kumpulan **tools gratis berbahasa Indonesia** untuk kebutuhan sehari-hari. Isinya mulai dari menghitung lama hari jadian, menghitung WR Mobile Legends, tasbih digital, mengubah angka menjadi terbilang rupiah, sampai cek weton dari tanggal lahir. Setiap tool adalah aplikasi Python sederhana dan open source. Kodenya bisa dibaca, dicek, dan dipakai siapa saja, dan dokumentasinya ditulis lengkap dalam Bahasa Indonesia.

## Kenapa Dibuat Open Source?

Banyak kalkulator online menyembunyikan rumusnya, jadi pengguna tidak bisa memeriksa apakah hasilnya benar. Di seri ini, setiap tool:

- **Menjelaskan rumusnya** lengkap dengan contoh hitung manual langkah demi langkah.
- **Diuji dengan unit test** memakai nilai referensi yang diketahui benar.
- **Mencantumkan sumber rujukan**, misalnya peraturan, standar, atau literatur, bila ada.
- **Berjalan di komputer sendiri** tanpa mengirim data ke server mana pun.

## Cara Memakai

Semua tool membutuhkan Python 3.8 atau lebih baru dan tidak butuh library tambahan:

```bash
git clone https://github.com/redyopa2929/<nama-tool>.git
cd <nama-tool>
python3 <nama-file>.py
```

Kalau dijalankan tanpa argumen, setiap tool masuk ke mode interaktif dan akan bertanya langkah demi langkah dalam Bahasa Indonesia. Petunjuk lengkap tiap tool ada di halaman dokumentasinya masing-masing.
